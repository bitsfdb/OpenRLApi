openrlapi

Self-contained, open-source Rocket League item catalog and asset API. Extracts UPK binaries and decrypted Coalesced files, parses game metadata, and serves endpoints with in-memory gzip caching.

Features

  • 12 languages: Full item names and player titles localized across INT, DEU, DUT, ESN, FRA, ITA, JPN, KOR, POL, PTB, RUS, TRK via ?l=.
  • Zero-copy in-memory caching: Pre-compressed gzip level 9 responses served in <1ms.
  • Preserving updater: Downloads and extracts game binaries without deletion, parses PE headers for GPsyonixBuildID, and auto-syncs items.ver.
  • Thumbnails: Batch texture extraction from _T_SF.upk packages via umodel into normalized PNGs.
  • Portability: Zero hardcoded server paths. Runs via Docker or standalone CLI.

Quickstart

# Clone repository
git clone https://github.com/bitsfdb/OpenRLApi.git
cd OpenRLApi

# Run with Docker
docker compose up -d

# Or run locally with Python
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m openrlapi.cli serve --port 8000

Endpoints

Method Path Query Params Description
GET /items.json l=LANG Master catalog (~29 MB) with instant gzip level 9 delivery
GET /items.ver — Current game version manifest hash
GET /v2/rl/products search, category, page, l Paginated products list with search
GET /v2/rl/products/{id} l=LANG Single item by ID (e.g. 358)
GET /v2/rl/categories — Item categories with counts
GET /v2/rl/attributes — Paint finishes and certifications
GET /titles.json l=LANG Player titles catalog from PsyNet
GET /v2/rl/titles category, search, l Paginated titles with color glow metadata
GET /v2/rl/titles/{id} l=LANG Single player title by ID or text
GET /thumbnails/{file}.png — Static item thumbnail renders

Examples

# Query master catalog in Spanish with gzip
curl -s "http://localhost:8000/items.json?l=ESN" -H "Accept-Encoding: gzip"

# Query single item in Polish
curl -s "http://localhost:8000/v2/rl/products/358?l=PL"

# Query PsyNet title in Spanish
curl -s "http://localhost:8000/v2/rl/titles/CRL_Analyst?l=ESN"

Configuration

Variable Default Description
OPENRL_HOST 0.0.0.0 Bind host address
OPENRL_PORT 8000 Bind port
OPENRL_WORKERS 1 Uvicorn worker count
OPENRL_RATE_LIMIT 300 Rate limit per minute per IP
OPENRL_DATA_DIR ./data Directory storing JSON databases
OPENRL_THUMBNAILS_DIR ./thumbnails Directory for extracted PNG thumbnails

CLI

openrlapi serve [--host 0.0.0.0] [--port 8000] [--workers 4]
openrlapi extract [--upk TAGame.upk] [--coalesced CookedPCConsole/]
openrlapi sync-titles [--build-id ID]
openrlapi extract-thumbs [--cooked-dir DIR] [--out DIR]
openrlapi update [--app Sugar]
